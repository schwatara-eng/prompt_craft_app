# PROMPT CRAFT

**AI VIDEO WORKFLOW** — 주제를 입력하면 기획부터 스토리보드, 대본, 이미지·영상 프롬프트까지 한 번에 정리하는 웹앱.

> 개발 상태: 로컬 테스트 중 (2026-10-09 기준). Groq API 연동 및 단계별 탭 출력 구현. 실제 생성 품질과 API 한도는 지속 검증 중.

## 주요 기능

- **입력:** 뉴스·콘텐츠 주제 또는 키워드, 영상 분위기/장르, 영상 길이
- **7개 결과:** 핵심 내용 → 콘텐츠 기획 → 스토리보드 → 대본 → 이미지 프롬프트 → 영상 프롬프트 → 내레이션
- **단계별 출력:** 결과가 준비되는 순서대로 탭에서 확인. 완료 탭은 검은 글씨, 미완료 탭은 회색으로 구분
- **화면 구성:** 결과를 긴 카드 목록으로 쌓지 않고 한 개의 탭 패널에 표시
- **진행 현황:** 제작 단계, 경과시간, 현재 단계 소요시간 표시
- **문서 표현:** 제목, 문단, 목록, 표 등 마크다운 형식 렌더링 및 결과 복사
- **품질 검사:** 필수 항목·최소 분량 등 단계별 검사 및 재작성 시도
- **요청 제한 대응:** Groq 요청을 순차 처리하고 분당 한도(HTTP 429)에 걸리면 대기 후 재시도. 이미 완료된 단계는 유지

## 기술 구성

| 구분 | 기술 |
| --- | --- |
| 프런트엔드 | HTML, CSS, JavaScript |

## 설치 및 실행

Node.js가 설치되어 있어야 합니다.

1. 프로젝트 폴더를 VSCode에서 엽니다.
2. 터미널에서 패키지를 설치합니다.

   ```bash
   npm install
   ```

3. 프로젝트 루트에 `.env` 파일을 만들거나 기존 파일에 아래 항목을 추가합니다.

   ```env
   GROQ_API_KEY=발급받은_API_키
   GROQ_MODEL=openai/gpt-oss-120b
   PORT=3000
   ```

4. 서버를 실행합니다.

   ```bash
   node server.js
   ```

5. 브라우저에서 `http://localhost:3000`을 엽니다.

서버를 종료하려면 터미널에서 `Ctrl + C`를 누릅니다. 서버 코드나 `.env`를 수정했다면 서버를 다시 실행해야 합니다.

> **보안:** `.env`를 Git에 커밋하지 마세요. `.gitignore`에 `.env`, `node_modules/`를 포함하세요. API 키는 브라우저 코드에 넣지 않습니다.

## 처리 흐름

```text
사용자 입력
  ↓
핵심 내용
  ↓
콘텐츠 기획
  ↓
스토리보드
  ↓
대본 → 이미지 프롬프트 → 영상 프롬프트 (순차 요청)
  ↓
내레이션
  ↓
최종 결과
```

서버는 생성 중 `progress`, `section`, `result`, `error` 메시지를 NDJSON 스트림으로 전달합니다. 프런트엔드는 완료된 `section`을 즉시 해당 탭에 표시합니다. 탭 전환을 위해 전체 생성이 끝날 때까지 기다릴 필요가 없습니다.

## API 한도 및 오류 대응

- **모델을 찾을 수 없음:** `.env`의 `GROQ_MODEL`과 계정에서 이용 가능한 모델을 확인합니다.
- **분당 토큰 제한(429):** 서버가 안내된 대기시간을 적용해 재시도합니다. 생성 시간은 길어질 수 있습니다.
- **일일 사용량 소진:** 자동 대기로 즉시 해결되지 않을 수 있습니다. 한도 초기화 후 재시도합니다.
- **품질 검사 실패:** 출력 분량이나 필수 항목을 충족하지 못하면 재작성합니다. 검증이 계속 실패하면 오류로 종료될 수 있습니다.

무료 한도 및 모델 제공 여부는 Groq 정책에 따라 달라질 수 있습니다. [Groq 콘솔](https://console.groq.com/)에서 확인하세요.
